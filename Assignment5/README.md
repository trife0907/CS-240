## Assembler
Run `python assembler.py` and enter your file name when prompted. Make sure your Python files and ASM files are in the same folder.
The files `fizzbuzz.mhc-ascii` and `fizzbuzz.mhc-bin` will be created.

## Disassembler
Run `python disassembler.py` and enter your file name when prompted. Same thing as the assembler.
The file `reconstructed.asm` will be created.
