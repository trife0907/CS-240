# Assignment 4: MIPS Game

All bitmap display settings are included as comments in the .asm files

## Tic-tac-toe
Classic tic-tac-toe. GUI displays the board, keyboard input through the Run I/O console.

## Blackjack
Simple blackjack, dealer stands on 17 (soft or standard). No splitting or doubling, only hit/stand. GUI displays value of hand up to 21.

## Custom game: Hidden bomb
There is a hidden bomb underneath one of the 9 tiles, uncover 5 safe tiles to win. Same GUI as tic-tac-toe.
