## Reflection
In this assignment, I learned the basics of MIPS, such as the difference between registers and memory and how to move data between the two. I also learned how to do the fundamentals that we typically see in high-level programming languages, such as conditional statements and loops. It was interesting to see how MIPS doesn’t really care about indentation, but rather it’s all about labels and jumping to different labels based on certain conditions. The part I found most difficult about this was honestly trying to stay organized with all of my code and syntax. Because MIPS doesn’t really indent for you, I had to make sure I was blocking all of my labels correctly and keeping track of where they are in the program to make sure my code doesn’t accidentally run lines of code it wasn’t meant to. I also enjoyed using the different system call codes and loading them in the $v0 register. From what I’ve seen so far, assembly is a very concrete language. You have to be extremely careful with what you are telling the program to do, as it is low-level and something can go wrong if you make a typo or a simple mistake. Overall, fun assignment! :D
